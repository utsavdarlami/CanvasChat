**EXTRACTION GUIDE**

**1. TITLE**: Does the document have an explicit title? If yes, extract verbatim. If no, generate a concise title (max 60 chars) from the main topic.

**2. ITEM TYPE**: Classify the document structure:

- "brief": Short summary or executive briefing
- "analysis": Analytical assessment or study
- "review": User feedback, critique, or opinion piece

- "summary": Executive summary or abstract

- "summary": High-level overview, few specifics (<10 key points)

- "comprehensive": Exhaustive with all available details

**4. SENTIMENT**: Emotional tone of the document:

**8. TEMPORAL FOCUS**: What time period do the EVENTS described cover?

- If no specific event time period exists → null

**9. SUMMARY**: 1-2 sentence summary of the document content focusing on main subject and key findings. If the source text is under 40 words, set to null.
